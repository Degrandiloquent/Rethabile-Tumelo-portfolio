# Rethabile Voluptuous Tumelo — Portfolio

A responsive portfolio for Rethabile Voluptuous Tumelo, a Setswana–English language practitioner and founder of Tswelelopele Lingua Services.

## Features

- Portfolio sections for services, education, skills, work samples, and contact.
- Motion effects with support for reduced-motion preferences.
- Illustrative editing and subtitling examples. These are sample content, not client work.
- Quote request form that prepares an email draft; the website does not submit or store form responses.
- Translation estimate of **R0.35 per word**. Other services require a separate quote.

## Run locally

The site uses plain HTML, CSS, and JavaScript; there are no build steps or package dependencies. From the project directory, start a local server:

```sh
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Deploy with Vercel

Import this GitHub repository as a new Vercel project. Select **Other** as the framework preset, leave the build command empty, and deploy the project root.
